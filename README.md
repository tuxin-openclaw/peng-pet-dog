# 小黄狗键鼠伙伴 (Peng Pet Dog)

一个纯 HTML5 Canvas 绘制的可爱黄身白面小柴犬键鼠互动网页，零外部依赖、开箱即用。

👉 **在线体验 (GitHub Pages)**：https://tuxin-openclaw.github.io/peng-pet-dog/

## 功能特点

- **双角色一键切换**
  - **🌼 蓝巾笑柴**：彩铅绘本风，天蓝斜纹背景、弯弯月牙笑眼、蓝底白雏菊侧结丝巾、漂浮粉爱心与手绘星星。
  - **🐕 红巾小柴**：深炭灰桌面桌宠风，水汪汪无辜大眼、红色波点三角巾与小金铃铛、经典卷卷柴犬尾。
- **全键盘实时同步**：按下任意键，桌面键盘对应键帽下压高亮，小狗左右爪自动分工精准点按。
- **按键放大与平滑淡出**：每次按键都会在画布两侧弹出立体 3D 放大键帽，停留后向上轻柔飘散并渐变消失。
- **鼠标移动与左右键独立高亮**：移动鼠标时小狗左爪同步带动桌面鼠标滑行；点击左键（珊瑚橙高亮）或右键（晴空蓝高亮）时对应半区清晰点亮并弹出提示，同时支持滚轮滚动与中键反馈。
- **明暗背景 & 机械键盘音效**：支持自由切换浅色/深色背景及 Web Audio API 合成的轻柔键鼠音效。

## 本地运行

直接用浏览器打开 `index.html`，或在项目目录启动任意静态服务器：

```bash
python3 -m http.server 8765
```
